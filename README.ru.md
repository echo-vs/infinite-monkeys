# Бесконечные обезьяны 🐒⌨️

[English](README.md) | **Русский**

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE) ![Python 3](https://img.shields.io/badge/Python-3-blue.svg) ![No dependencies](https://img.shields.io/badge/dependencies-none-brightgreen.svg)

Симулятор [теоремы о бесконечных обезьянах](https://ru.wikipedia.org/wiki/Теорема_о_бесконечных_обезьянах) с графическим интерфейсом. Тысячи обезьян бьют по случайным клавишам, а программа в реальном времени следит, не напечатали ли они нужные слова и фразы.

Используется только стандартная библиотека Python, сторонних пакетов нет. Несмотря на Python, программа быстрая: вся тяжёлая работа (генерация случайности, перевод байтов в клавиши, поиск подстрок) идёт в коде на C, а у каждого ядра процессора свой процесс.

| Машина | 1000 обезьян, турбо |
|---|---|
| AMD Ryzen 5 7500F (6 ядер / 12 потоков), Gentoo | ~2,5 млрд символов/с |
| Тестовая ВМ на 8 ядер | ~480 млн символов/с |

## Возможности

- **Стаи обезьян.** Можно запустить несколько стай одновременно, у каждой своя клавиатура, численность и скорость. Например, одна стая печатает по-русски, а другая по-английски.
- **Честная случайность.** Случайные байты берутся из `os.urandom`, и у каждой клавиши ровно одинаковая вероятность: байты, которые дали бы перекос, отбрасываются.
- **Живая слежка.** Вводишь слова или фразы, по одной в строке. Каждая стая следит только за тем, что может напечатать на своей клавиатуре. Фразы можно добавлять на ходу, не останавливая обезьян.
- **Рекорды.** Для каждой фразы видно лучшую попытку (например, `shakespe···`), кто напечатал первым, сколько раз найдено и сколько примерно ждать при текущей скорости.
- **Фразы на стыке кусков** тоже находятся, если фраза разорвана между двумя кусками текста.
- **Живой экран**, где видно, как печатают обезьяны, найденное подсвечено.
- **Скорость**: турбо (сколько тянет процессор) или от 1 до 60 нажатий в секунду на обезьяну, чтобы смотреть, как они печатают.
- **Сохранение всего напечатанного** в папку, с общим лимитом размера (например, 2 ГБ, после чего запись прекращается) и лимитом на один файл (файлы делятся на части).
- **Поиск в сохранённом**: любое слово или фраза по всем сохранённым файлам, параллельно на всех ядрах. Если ничего не найдено, показывает самую близкую попытку.

## Установка

Нужен **Python 3** с модулем **Tkinter** (стандартная библиотека Python для окон). Больше ничего не нужно, `pip install` делать не надо.

Разработано и проверено на Python 3.14 под Linux (Fedora, Gentoo).

### Windows

1. Скачай Python с [python.org](https://www.python.org/downloads/windows/).
2. В установщике проверь, что отмечены:
   - **«Add python.exe to PATH»**
   - **«tcl/tk and IDLE»** (в разделе *Customize installation*, по умолчанию включено). Это и есть Tkinter.
3. Скачай проект (на GitHub `Code → Download ZIP` и распакуй, либо `git clone`).
4. Открой папку проекта, напиши в адресной строке `cmd` и нажми Enter.
5. Запусти:
   ```bat
   py monkeys.py
   ```

> В Python из Microsoft Store Tkinter тоже есть.

### Linux

Поставь Python и Tkinter менеджером пакетов своего дистрибутива:

| Дистрибутив | Команда |
|---|---|
| Debian / Ubuntu / Mint / Pop!_OS | `sudo apt install python3 python3-tk` |
| Fedora / RHEL / CentOS Stream | `sudo dnf install python3 python3-tkinter` |
| Arch / Manjaro / EndeavourOS | `sudo pacman -S python tk` |
| openSUSE | `sudo zypper install python3 python3-tk` |
| Void Linux | `sudo xbps-install python3 python3-tkinter` |
| Alpine | `sudo apk add python3 py3-tkinter` |
| Gentoo | см. ниже |

#### Gentoo

В Gentoo Tkinter включается USE-флагом `tk` у пакета `dev-lang/python`:

```sh
# включить USE-флаг tk для Python
echo "dev-lang/python tk" | sudo tee -a /etc/portage/package.use/python

# пересобрать Python с новым флагом
sudo emerge --ask --oneshot --changed-use dev-lang/python
```

Если у тебя `/etc/portage/package.use` не папка, а файл, допиши строку в этот файл.

#### Проверка, что Tkinter работает

```sh
python3 -m tkinter
```

Должно появиться маленькое окно. Если вместо него ошибка `ModuleNotFoundError: No module named 'tkinter'`, значит, пакет с Tkinter ещё не установлен.

#### Запуск

```sh
git clone https://github.com/<твой-ник>/infinite-monkeys.git
cd infinite-monkeys
python3 monkeys.py
```

## Как пользоваться

### Вкладка «Обезьяны»

1. **Стаи.** По умолчанию есть две стаи, «Русские» и «Англичане», по 1000 обезьян. Кнопки «Добавить» / «Изменить» / «Удалить» или двойной клик по стае. У стаи настраивается:
   - число обезьян;
   - число процессов (0 = авто, потоки процессора делятся между стаями);
   - клавиатура: готовая (русская, английская, со знаками, цифры…) или свой набор символов, плюс клавиша пробела;
   - скорость: турбо или от 1 до 60 нажатий в секунду на обезьяну.
2. **Что ищем.** Одно слово или фраза в строке. Поле быстрого добавления работает и во время печати.
3. **Сохранение** (по желанию): папка, общий лимит в ГБ (0 = без лимита), размер одного файла в МБ и галочка «остановить обезьян, когда лимит заполнен».
4. Жми **▶ Запустить обезьян** или **F5**. **Esc** останавливает.

В таблице слежки для каждой фразы видно: сколько раз найдено, лучшую попытку, прогресс, кто нашёл первым и сколько примерно ждать. В журнал пишется каждая первая находка и каждый новый рекорд («Почти!»).

### Вкладка «Поиск в сохранённом»

Выбери папку (всю папку сохранений, один запуск или одну стаю), введи слово или фразу и нажми Enter. В результатах видно стаю, номер обезьяны, номер символа и контекст, найденное выделено `【вот так】`.

### Формат сохранения

```
сохранения/
└── 2026-09-23_17-38-06/          папка на каждый запуск
    ├── 1_Русские/                папка на каждую стаю
    │   ├── meta.json             клавиатура, число обезьян, фразы, время старта
    │   ├── w00_0001.txt          процесс 0, часть 1
    │   ├── w00_0002.txt          процесс 0, часть 2
    │   └── w01_0001.txt …
    └── 2_Англичане/ …
```

Каждая строка `.txt`-файла:

```
<номер обезьяны><TAB><номер первого символа><TAB><текст>
```

Весь текст одной обезьяны лежит по порядку в файлах одного процесса, поэтому его можно собрать целиком.

## Сколько ждать?

Если на клавиатуре `N` клавиш, фраза длиной `L` в среднем встречается примерно раз на `N^L` символов. Каждый лишний символ умножает ожидание на `N`.

При ~2,5 млрд символов/с:

| Фраза | Клавиатура | Длина | Среднее ожидание |
|---|---|---|---|
| monkey | английская, 27 | 6 | < 1 секунды |
| shakespe | английская, 27 | 8 | ~2 минуты |
| обезьяна | русская, 33 | 8 | ~10 минут |
| shakespear | английская, 27 | 10 | ~1 сутки |
| shakespeare | английская, 27 | 11 | ~26 дней |
| быть или не быть | русская, 33 | 16 | ~25 млн лет |
| to be or not to be | английская, 27 | 18 | ~740 млн лет |

У обезьян нет памяти: каждую секунду шанс одинаковый, сколько бы они уже ни печатали.

## Как это устроено

- `engine.py` — обезьяны. Они распределены по процессам (`multiprocessing`, `spawn`). Каждый процесс берёт случайные байты из `os.urandom` и одним вызовом `bytes.translate` превращает их в номера клавиш, байты, дающие перекос, отбрасываются. Текст хранится как байты-номера клавиш, фразы кодируются так же и ищутся через `bytes.find`. От предыдущего куска каждой обезьяны хранится короткий хвост, поэтому фразы на стыке кусков не теряются. Счётчики находок отправляются в окно пачками раз в 0,1 с.
- `search.py` — поиск по сохранённым файлам. Одна задача на пару «стая, процесс» в пуле процессов, куски каждой обезьяны склеиваются обратно.
- `monkeys.py` — окно на Tkinter.

## Структура проекта

```
monkeys.py    окно, точка входа
engine.py     процессы-обезьяны, честная случайная печать, живая слежка, сохранение
search.py     параллельный поиск в сохранённом
```
